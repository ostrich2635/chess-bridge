# Chess Bridge ♞

A premium SaaS-style web application to monitor your Chess.com games and instantly analyze them on Lichess with free cloud analysis.

## ✨ Features

- **🎨 Modern Dark Glassmorphism UI**: Built with Space Grotesk typography, ambient floating background mesh orbs, and responsive CSS grid layouts.
- **⚡ Live Game Monitoring**: Connect your Chess.com account to track your latest games and preview results in real-time.
- **🚀 One-Click Lichess Analysis**: Instantly import any finished game to Lichess with your personal API token for deep cloud analysis with Stockfish.
- **📊 Post-Game Review**: Clean game preview cards with result accent styling (Win/Loss/Draw), opening names, time controls, and persistent game history stored in your browser's localStorage.
- **🔒 Secure & Lightweight**: Vite + TypeScript architecture with zero heavy frameworks, running fully client-side.

## 🛠️ Tech Stack

- **Frontend**: Vite, TypeScript, Vanilla CSS (Custom Properties, Glassmorphism design system)
- **Hosting**: Designed for zero-config static deployment on GitHub Pages via automated CI/CD workflows

## 📦 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/ostrich2635/chess-bridge.git
   cd chess-bridge
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start local development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
